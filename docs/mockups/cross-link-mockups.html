Link between a lab standard and its competency standard

Three placements. Each option shows the lab standard page first and the competency standard page second. The example course is AEOSIB, Marine Engine Operation and Maintenance. All 171 courses have both documents, so the link always has a target.

A. Button in the existing button row

The new button sits next to Download and Print. On the lab page that is the score bar, which stays visible while scrolling on desktop. Smallest change: one button per page, no new CSS.
